¡Bienvenido al código fuente de mi portafolio personal! Este proyecto muestra mi experiencia, habilidades y proyectos destacados como desarrollador especializado en arquitecturas backend escalables y aplicaciones web modernas.

### 🚀 Tecnologías

Este portafolio está construido con tecnologías web modernas, enfocándose en el rendimiento y una arquitectura limpia:
- **[Astro](https://astro.build/)**: Para generación de sitios estáticos increíblemente rápidos.
- **[React](https://reactjs.org/)**: Para componentes de interfaz de usuario interactivos.
- **[Tailwind CSS](https://tailwindcss.com/)**: Para estilos rápidos, minimalistas y adaptables.
- **[Anime.js](https://animejs.com/) & Embla Carousel**: Para animaciones e interacciones fluidas, atractivas y carruseles arrastrables.
- **[i18next](https://www.i18next.com/)**: Para un soporte bilingüe perfecto (Inglés/Español).

### ✨ Características
- **Diseño en Modo Oscuro**: Presenta un elegante fondo oscuro `#020618` con acentos vibrantes en tonos *teal* y degradados.
- **Bilingüe**: Soporte i18n completamente integrado (Inglés/Español).
- **Interfaz Interactiva**: Carruseles de proyectos arrastrables, líneas de tiempo profesionales responsivas y animaciones dinámicas al pasar el cursor (Card Fan).
- **Optimizado para SEO y Rendimiento**: Aprovecha la arquitectura de Astro para velocidades de carga ultrarrápidas.
